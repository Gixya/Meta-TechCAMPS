# Meta — Tech CAMPS 2026

## Sobre o projeto

Este projeto foi desenvolvido para o Tech CAMPS 2026 com o objetivo de explicar como a tecnologia conecta pessoas e como funcionam os algoritmos de recomendação nas redes sociais.

O site apresenta informações sobre a história da Meta, seus principais produtos, suas tecnologias e os impactos do uso das redes sociais.

## Funcionalidades

- História e linha do tempo da Meta.
- Apresentação de produtos e tecnologias.
- Explicação sobre algoritmos de recomendação.
- Exemplos de aplicações, benefícios e desafios.
- Simulador interativo Bugstagram, que demonstra como os interesses e as interações podem influenciar um feed de publicações.

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript

## Como executar

1. Baixe ou clone este repositório.
2. Abra o arquivo `index.html` no navegador.
3. Acesse a seção **Experiência** para testar o Bugstagram.

Não é necessário instalar programas ou configurar um banco de dados.

## Observação

O projeto tem finalidade exclusivamente educativa e não possui vínculo, parceria ou patrocínio oficial da Meta. O Bugstagram é uma simulação simplificada e não reproduz o algoritmo real da empresa.
